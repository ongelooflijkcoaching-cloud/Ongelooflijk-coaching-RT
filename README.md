# Ongelooflijk Coaching & RT

Dit is de statische website van Ongelooflijk Coaching & RT, voorbereid voor GitHub Pages.

## Publiceren met GitHub Pages

1. Maak op GitHub een nieuwe repository aan.
2. Pak het ZIP-bestand op je computer uit.
3. Upload **de inhoud van de uitgepakte map** naar de hoofdmap van de repository. `index.html` moet dus direct bovenaan staan.
4. Open in de repository **Settings > Pages**.
5. Kies bij **Build and deployment** voor **Deploy from a branch**.
6. Selecteer de branch **main**, de map **/(root)** en klik op **Save**.
7. Wacht enkele minuten. GitHub toont daarna de openbare websitelink.

De website gebruikt geen database of servercode en kan daarom rechtstreeks via GitHub Pages worden gepubliceerd.
